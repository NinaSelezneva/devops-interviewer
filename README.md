# devops-interviewer

Тренажёр для подготовки к собеседованию на позицию **Senior DevOps инженера**: 145 вопросов по 15 темам с подробными эталонными ответами, теорией по каждой теме, тренировкой карточками с интервальным повторением и пробным собеседованием с таймером.

Какие вопросы задают и откуда они взяты, описано в [docs/research.md](docs/research.md).

## Быстрый старт

Сборка не нужна: откройте `web/index.html` в браузере.

Онлайн-версия: https://ninaselezneva.github.io/devops-interviewer/ (деплоится автоматически при пуше в `main` через `.github/workflows/pages.yml`).

Или через локальный сервер:

```bash
npm start          # пересобирает контент и запускает http://localhost:8080
```

## Возможности

- **Обзор**: прогресс по каждой теме и общая статистика.
- **Тема**: теория и шпаргалка, список вопросов с фильтрами по уровню, типу и статусу.
- **Тренировка карточками**: вопрос → свой ответ → эталон → самооценка. Используется система Лейтнера: вопросы, на которые вы ответили «Не знаю», возвращаются в той же сессии и раньше попадают в повторение. Горячие клавиши: `Пробел` — показать ответ, `1/2/3` — оценка.
- **Пробное собеседование**: случайные вопросы из выбранных тем с чередованием тем, таймер на ответ, итоговый процент и разбивка по темам, история попыток.
- **Поиск** по тексту вопросов, ответов и тегам.
- Тёмная и светлая тема, экспорт и импорт прогресса в JSON (прогресс хранится в `localStorage` браузера).

## Структура

```
content/          # вопросы и теория в Markdown — источник правды
  01-linux.md ... 15-behavioral.md
scripts/build.mjs # сборщик: content/*.md → web/data.js (+ валидация)
web/              # статическое приложение без зависимостей
  index.html  app.js  styles.css  data.js (генерируется)
docs/research.md  # анализ вопросов и источники
```

## Как добавить вопрос

Допишите в нужный файл `content/*.md`:

```markdown
## Q: Текст вопроса?
level: senior          # middle | senior | lead
type: scenario         # theory | practice | scenario | design | behavioral
freq: 3                # 1..3 — как часто встречается на собеседованиях
tags: kubernetes, сеть

Эталонный ответ в Markdown: списки, таблицы, блоки кода, цитаты-подсказки (>).
```

Затем выполните `npm run build`. Сборщик проверит метаданные и сообщит об ошибках. Новая тема — это новый файл с front matter (`id`, `title`, `icon`, `order`, `summary`); текст до первого `## Q:` становится теорией темы.

ID вопроса вычисляется из его текста, поэтому если переформулировать вопрос, прогресс по нему сбросится. Чтобы этого избежать, задайте стабильный `id:` в метаданных вопроса.
